Flagship Engineering Project • Lab Environment

Perishable Distribution Center Network Operations Lab

A warehouse-focused network simulation designed around the technology and operational dependencies of a high-volume, temperature-controlled distribution center.

Aruba WLANVLANsDHCP/DNS Fortinet SD-WANRFZebra Honeywell VoiceMonitoring

Engineering Objective

Keep warehouse technology connected and operational by designing a segmented network, defining service dependencies, and documenting repeatable troubleshooting workflows. The project connects network infrastructure to the business processes it supports: receiving, inventory, picking, voice-directed work, labeling, staging, and shipping.

What this demonstrates

  • Layer 1–3 network troubleshooting
  • VLAN and IP addressing design
  • Enterprise WLAN troubleshooting concepts
  • DHCP/DNS dependency analysis
  • WAN and SD-WAN troubleshooting concepts
  • Network-connected endpoint isolation

Operational mindset

  • Determine business impact before changing infrastructure
  • Establish scope and isolate the failure domain
  • Collect evidence before remediation
  • Validate service restoration
  • Document root cause and escalation data

Incident Response Case Studies

Each scenario will be expanded with screenshots, evidence, root cause and validation as the lab is implemented.

INC-001

Zebra Printer Unreachable

Planned

Determine whether the failure is physical, switch-port, VLAN, DHCP, gateway, DNS or endpoint related.

ping <printer-ip>
ipconfig
arp -a
nslookup <printer-hostname>
tracert <printer-ip>
INC-002

RF Scanner Intermittent Connectivity

Planned

Correlate affected warehouse zones with AP association, RF conditions, roaming, VLAN and DHCP behavior.

client → AP → RF → VLAN → DHCP → gateway → application
INC-003

Honeywell Voice Connectivity

Planned

Separate device, wireless, network-service and voice-application failure domains.

association → signal → roaming → IP → gateway → voice service
INC-004

Warehouse AP Failure

Planned

Check AP reachability, PoE, switch port, uplink, VLAN and neighboring coverage.

AP → PoE → switch port → uplink → VLAN → client validation
INC-005

Primary WAN Failure

Planned

Validate SD-WAN health detection, backup path selection, tunnel state and application reachability.

WAN health → path selection → tunnel → route → application
INC-006

DHCP Scope Exhaustion

Planned

Investigate client configuration, scope utilization, VLAN and DHCP relay/helper behavior.

client IP → VLAN → relay → scope → lease → gateway
